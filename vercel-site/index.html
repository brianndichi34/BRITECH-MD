BRITECH MD

WhatsApp Multi-Device Assistant

An independently built Node.js and Baileys WhatsApp assistant by Brian Ndichi.

Features

  • General and utility commands
  • Group information and moderation tools
  • Optional AI replies through the OpenAI API
  • Linked-device pairing support

Run the bot

  1. Use Node.js 20 or newer.
  2. Install dependencies with npm install.
  3. Configure environment variables using .env.example.
  4. Pair WhatsApp with npm run session.
  5. Start with npm start.

Hosting note: this page is informational only. The WhatsApp client must run as an always-on worker with persistent session storage. Do not deploy the bot process as a Vercel Function.
