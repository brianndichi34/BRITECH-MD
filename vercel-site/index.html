Deployment options

Deploy on KataBump Deploy on Railway Deploy on Render Deploy on Heroku Docker / VPS guide

KataBump: upload the ZIP or clone the repository, configure Node.js 20+, environment variables and persistent session storage. Railway and Render may incur charges. Hosting providers' availability and pricing can change.

Quick start

  1. Download the repository ZIP or clone it.
  2. Install dependencies using npm install.
  3. Generate a WhatsApp session with npm run session or the private GitHub Actions workflow.
  4. Store the entire auth folder on persistent storage.
  5. Start the bot with npm start.

The WhatsApp bot needs a continuously running worker and persistent authentication files. Do not deploy the bot process as a Vercel Function. This page is informational only.
